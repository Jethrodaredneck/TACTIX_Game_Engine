# TACTIX Editor Foundation 0.3

Visible editor milestone built on the Stage 3 docking + AI bridge base.

## Added
- Runtime scene entities now directly drive Metal rendering.
- Built-in Cube, Sphere, Plane, Cylinder, Capsule and Cone mesh generation.
- Hierarchy toolbar for creating Cube/Sphere/Plane primitives.
- Duplicate/Delete and Undo/Redo entity operations.
- Inspector Position/Rotation/Scale edits immediately affect rendered entities.
- Selection tint in the viewport.
- Basic `.tactixscene` Save/Load to `Assets/Scenes/Main.tactixscene`.
- Neutral gray TACTIX default primitive shading with a faint ghost-logo treatment.

## Still intentionally deferred
- Mouse picking in the viewport.
- Transform gizmos.
- Editor camera navigation.
- Asset drag/drop and imported mesh rendering.
- Full material system / RenderWorld extraction optimization.
- Play mode.
